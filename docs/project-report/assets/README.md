- `srm-logo.jpeg`: extracted without redesign from page 1 of the user-supplied `Example Docs/IMS_BCA_Project_Report.pdf`. Used only for the requested same-institution college-report template; it does not assert institutional approval. Institutional marks remain their owner's property.
- `fonts/STIXGeneral*.ttf`: full STIX General font resources obtained from the Matplotlib repository's `lib/matplotlib/mpl-data/fonts/ttf/` directory through the GitHub contents API. `fonts/LICENSE_STIX` is the accompanying licence notice. This serif family matches the supplied reference's embedded typeface.
- `fonts/DejaVuSansMono.ttf`: the environment's installed DejaVu Sans Mono font, redistributed with `fonts/LICENSE_DEJAVU`, for source listings. Embedding in PDF/Word does not alter application code.
- `diagrams/*.png`: deterministic drawings generated by `scripts/generate-report-diagrams.py` from reviewed application relationships and workflows. No stock diagrams or imagined connected services were used.
- `screenshots/*.png`: genuine Chromium captures of the locally built Parkline application at the reviewed commit. There are no AI-generated UI mockups. `source/browser-evidence.json` records browser/version/viewports and assertions.
- `screenshots/11-mobile-upper-view.png`: print excerpt of the top 750 image-pixel rows of `11-mobile-overview.png`. It preserves the complete captured width and the observed horizontal overflow; the full unedited capture is also retained.

The report prints eight of the screen captures. Post-arrival success, duplicate validation and new-location result images are retained as supporting evidence rather than repeated to increase the page count.
